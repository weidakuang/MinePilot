# MinePilot Rebuild Charter

MinePilot is an Apache-2.0 Forge project for Minecraft Java 26.2. The active
branch is a clean rebuild and currently contains no Agent behavior.

The long-term product direction may include a visible AI teammate, but no
capability is promised merely because it existed in an earlier implementation
or appears in a design document. Each capability must be reintroduced only
after an explicit user instruction and must be verified from real game state.

The project will not count model prose, internal task output, scripted world
mutation, or fixture-only success as proof that an Agent acted. Evidence must
come from the actual body, inventory, world, menus, entities, and vanilla
statistics.

Public project content is English. Runtime chat and test inputs may be
multilingual. Credentials and private gameplay data must never be committed.
