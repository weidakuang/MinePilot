# M3 companion verification

## Exit criteria

The companion must survive a 100-hour world and pass the scenario matrix for
chat, follow, waypoint travel, inventory ownership, construction, farms,
transport, PVE/PVP, recovery, and supported workstation/mod adapters.

## Current result

`NOT_RUN`. The SPI, UI, MCP, memory, and many atomic skills exist; no 100-hour
soak or complete natural-world companion scenario archive is available.

The public M3 evidence protocol is now fail-closed in
[`e2e/m3_protocol.py`](../../e2e/m3_protocol.py). A future release run must
bind every shard to one exact product JAR and source commit, use a real
dedicated server plus normal client and configured model, and provide an
independent read-only Observer result. It also requires at least 50 natural
language companion cases, 30 unseen-site building cases, three unseen
variants for every farm and machine capability label, restart/chunk-unload/
interruption coverage, 100 hours of world time, and the 10,000-waypoint /
100,000-asset query budgets. Unit fixtures only verify this protocol; they do
not satisfy the M3 gate.
